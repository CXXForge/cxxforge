# CXXForge Documentation

This directory contains the maintained documentation for CXXForge.

## Sections

- [Architecture](architecture/README.md) — system architecture and technical specifications.
- [Development](development/documentation-governance.md) — documentation lifecycle, review, and publication policy.

## Authority and status

The Git repository is the canonical source of truth for project documentation. A document marked `draft` is a proposal and must not be treated as an approved design. Only the founder may approve architecture specifications and architectural decisions.

See the [documentation governance policy](development/documentation-governance.md) for the complete lifecycle and status definitions.
